## 🐶About Our Neighborhood Pharmacy Map

#### "Our Neighborhood Pharmacy Map" is a service that helps users find nearby pharmacies.

### Key Features
1. Role separation: admin, pharmacist, general user  
2. Bookmark feature for general users  
3. Comment replies by pharmacist users  
4. Pharmacy search functionality  
5. Report inappropriate reviews  
6. Admin features: hide reported comments, ban users  

## Main Screen
<img width="1909" alt="image" src="https://user-images.githubusercontent.com/116015708/234590636-9ec03647-74ab-4fbe-a2a3-070b63da8446.png">

Users can search pharmacies by name or address.  
Clicking the button at the bottom right displays a list of pharmacies around the selected location.

## Pharmacy Detail Page
<img width="1909" alt="image" src="https://user-images.githubusercontent.com/115776596/235055243-f1f45afb-7846-4757-82e9-6a5d4e8fa077.png">

Clicking on a pharmacy card opens a detailed popup.  
The detail page includes address, phone number, real-time operating status, business hours, and user reviews.  
Logged-in general users can write, edit, delete, and report reviews. Pharmacist users can reply, edit, and delete responses.

## General User My Page
<img width="902" alt="image" src="https://user-images.githubusercontent.com/116015708/234591068-a995f924-ee19-44e2-bce4-79dd34aaa717.png">

Users can view and edit their personal info (except email).  
They can also view a list of their bookmarked pharmacies and submitted reviews, with links to each pharmacy detail page.

## Pharmacist My Page
<img width="854" alt="image" src="https://user-images.githubusercontent.com/116015708/234592236-a151c340-7785-4154-afde-11a9e9f89681.png">

Pharmacist users can see the page for the pharmacy they operate.  
Pharmacist verification is done by admin approval of submitted business and pharmacist licenses at registration.

## Admin Page
<img width="1807" alt="image" src="https://user-images.githubusercontent.com/116015708/234592613-0214bcfe-4d27-4006-be0d-2f111b0b427c.png">

Admin can manage malicious reviews and user accounts (ban/suspend users), and approve pharmacist verification.  
Reported reviews automatically appear in the review report tab.
